# AI+金融财报分析系统完整全栈框架 v5.0

## 一、核心思路与原则
利用大模型的能力对上市公司年报进行解读，从财务报表、行业性质等角度分析该企业年度经营情况、发展前景和投资价值。
整个系统涉及大模型、代码、数学计算，整体原则如下：
1. **LLM 只做语义理解**：理解文字、打标签、逻辑推演、检索信息。**LLM 不参与任何数学计算。**
2. **代码只做数学运算**：提取数字、换算单位、勾稽校验、MAD 偏差计算、余弦相似度匹配、概率分配评分。**代码不进行任何语义理解。**
3. **硬标签查表优先**：客观行业分类（同花顺三级/二级行业）从 CSV 数据源查表确定，LLM 只在 CSV 查不到时才降级推断。
4. **同行匹配用向量而非文本**：A2 层不再依赖定性软标签做 Jaccard 文本匹配，改为基于 6 维财务等级向量的余弦相似度——LLM 画出"数字画像"，代码做纯数学定位。
5. **整体实现流程**：先看行业定性并画数字画像 → 再用向量匹配找同行基准 → 提取财务数据并校验 → 发现异常偏差 → 结合财报原文和外部宏观情报找原因 → 给出概率化的综合判断。

## 二、系统六层架构详解

### 🔹 第0层：PDF数据提取
*   **任务**：把一份几百页的上市公司年度报告 PDF，拆解成电脑能直接读懂的 JSON 格式文件。
*   **实现方式**：使用开源工具（如 MinerU / pdfplumber）自动解析和切分。
*   **最终输出结果**：一份包含四大区块的 JSON 文件：
    *   `财务数据部分`（三大报表的表格原始数据，通常是 OCR 识别后的文本格式）；
    *   `管理层讨论与分析部分`（全是文字，描述公司去年的经营情况、风险等）；
    *   `附注明细部分`（表格辅助信息，比如存货的具体构成）；
    *   `公司基本情况部分`（公司的主营业务介绍、行业分类归属）。

### 🔹 A层：找对比基准（行业定性 + 数字画像）

#### A0层：外部宏观情报提取
*   **任务**：从互联网获取该公司的行业宏观背景信息，作为 D1 路 2 发散假设的外部知识源。
*   **实现方式**（两段式 prompt + SerpAPI）：
    1.  **搜索词生成**（`a0_search_query`）：LLM 根据公司信息生成 4 个维度的搜索词——宏观周期与政策、上游原材料供需、下游终端需求、宏观黑天鹅。每维度至少 3 条，软规则限定：含"今年"时间词、不输出归因结论、不出现主观判断词。
    2.  **联网搜索**：代码用搜索词调用 SerpAPI，获取原始搜索结果。
    3.  **宏观事实提取**（`a0_macro_facts`）：LLM 从搜索结果中提取结构化事实，屏蔽"强烈看好/强烈卖出"等主观推荐语，仅输出客观数据（价格涨跌幅、供需变化、政策文件）。每一条事实要求标注来源和日期，数据冲突时留空。
*   **输出结果**：4 个维度的宏观事实列表，每条含事实描述、来源、日期。

#### A1层：语义提取与打标签 + 财务数字画像
*   **任务**：LLM 读 JSON 里的文字部分（公司基本情况和行业背景），做两件事：
    1. 给出客观行业分类（硬标签）；
    2. 给出 6 维财务特征等级（数字画像）。
*   **硬标签获取**（三级优先路径）：
    *   **第一步**：优先从 `data/industry/thf_industry_classification.csv`（同花顺 iFinD，5536 只 A 股）通过**股票代码精确匹配**。匹配到则直接确定硬标签，LLM 不再输出硬标签（节省 token + 消除幻觉）。
    *   **第二步**：股票代码匹配不到时，用**公司名模糊匹配**（CSV 简称 vs 公司全称）。
    *   **第三步**：CSV 查不到 → LLM 同时输出硬标签 + 数字画像。
    *   **第四步**：LLM 不可用 → 关键词规则降级。
*   **财务数字画像（核心变更）**：LLM 输出的不是定性文本，而是 6 个维度的财务等级数组：

    | 维度 | 极高 | 高/中高 | 中等 | 低 |
    |------|------|---------|------|-----|
    | 毛利率水平 | >70% | 40%-70% | 20%-40% | <20% |
    | 净利率水平 | >30% | 15%-30% | 5%-15% | <5% |
    | 总资产周转率 | >1.5次 | 1-1.5次 | 0.5-1次 | <0.5次 |
    | 资产负债率 | >80% | 60%-80% | 30%-60% | <30% |
    | 研发费用率 | >15% | 8%-15% | 3%-8% | < 3% |
    | 销售费用率 | >40% | 20%-40% | 10%-20% | <10% |

    输出格式示例：`["极高","极高","低","低","低","高"]`，不加任何解释文字。

#### A2层：数字画像匹配同行（纯代码向量运算）
*   **任务**：基于 A1 的数字画像，在同行中找最相似的 3~5 家企业，计算横向基准。
*   **行业池子**：从同花顺**二级行业**（而非三级）中选出全部公司作为候选池。三级行业过细（257 个），很多子行业只有三五家公司，样本不足。
*   **数据来源**：每家的财务指标通过 **akshare 实时获取 + 内存缓存**（不写磁盘，避免本地累积无用数据）。
*   **匹配流程**：
    1.  对**目标公司 + 每家同行**：读取 5 年财务数据（不满 5 年取全部）。
    2.  每年数据按上述阈值映射为 6 维等级数组，得到 5 个 `[6]` 数组。
    3.  逐维取**中位数**合并为 1 个 `[6]` 等级数组（中位数抗暴雷，优于均值）。
    4.  等级映射为数值：极高=1.0，高/中高=0.8，中等=0.5，低=0.2。
    5.  计算目标公司与所有同行的**余弦相似度**（看形状而非绝对大小）。
*   **双池输出**：
    *   **Top 5**：最相似的 5 家公司——给 E 层做横向对比展示。
    *   **Top 20%**（保底 5 家）：前百分之二十最相似的公司——给 C 层算 MAD 基准。样本量更大，MAD 统计更稳健。
    *   **自适应降级**：如果同行数 < 10，MAD 池与 Top 5 合并；如果同行数 < 5，报"同行不足"，跳过 MAD 匹配。

### 🔹 B层：提取财务数据
*   **B0层：表头语义指引**
    *   **任务**：大模型只看财务报表的表头文字，分辨表格名称和单位。
    *   **输出结果**：
        *   统一字段名（把"营业收入"、"营业总收入"等统一映射为系统标准字段 `Revenue_Total`）；
        *   提取单位（元/万元/千元）；
        *   提取报表类型（合并报表 / 母公司报表）。
*   **B1层：代码准确提取表格数据与勾稽校验**
    *   **任务**：纯代码（Pandas）根据 B0 指引，定位到表格的具体行和列，抓取数字。
    *   **单位换算**：把单位统一换算成"元"（万元 × 10000）。
    *   **勾稽关系校验**：代码提取完毕后，校验最基础的会计恒等式：
        *   `资产总计` = `负债总计 + 所有者权益总计`
        *   `期末未分配利润` ≈ `期初未分配利润 + 本期净利润 - 本期分红`
    *   **分支处理**：
        *   **校验失败**：跳过 B+/C/D 三层，在 E 层输出 `【系统异常阻断：PDF数据源损坏或低劣造假，请人工核验原文件】`。
        *   **校验成功**：数据传给下一层，同时母公司报表的货币资金、负债数据单独提取备用。

### 🔹 B+层：内部逻辑检查（财务异常初筛）
*   **任务**：用代码查财报数据是否有"逻辑硬伤"。
*   **具体计算 3 项指标**：
    1.  **净现比/收现比**：`经营活动现金流净额 / 净利润` 和 `销售商品收到的现金 / 营业收入`。两比值显著低于 0.6 时标记异常。
    2.  **存贷双高**：`货币资金总额` 和 `有息负债总额` 同时处于高位。
    3.  **母子资金分离度**：`合并报表货币资金 - 母公司报表货币资金` 差值极大。
*   **输出结果**：异常清单如 `["存贷双高可疑","利润含金量极低"]`，但不下最终定论，交给 D 层综合判断。

### 🔹 C层：MAD 偏差异常检测
*   **任务**：用 A2 提供的同行中位数做基准，计算"这家公司的指标偏离同行平均水平多远"。
*   **算法**：采用 **MAD（中位数绝对偏差）**，因其比标准差更抗极端值（财务数据常有暴雷值）。
*   **输出结果**：异常波动清单，如 `[指标：存货周转率，实际值：0.1，偏离度：低于同行中位数 3.2 倍 MAD]`。

### 🔹 D层：原因查找与概率分配
*   **任务**：对于每一个异常，分两路分析原因，再综合分配概率。
*   **D1层：双路径推理**（两条路严格隔离，互不越界）
    *   **路1（查原文）**：LLM 只读年报的【附注】和【管理层讨论】原文，提取客观解释。如果原文含糊其辞，标记为"无直接解释"。
    *   **路2（外部情报推演）**：LLM 不看原文，而是拿 **A0 层的宏观事实 + A1 的行业标签 + 财务数字画像 + 偏差数据**，发散出几种合理的互斥假设。
    *   先分析 B+ 层异常（基本只有两种可能：行业本身性质或造假），再分析 C 层偏差。
*   **D2层：概率分配**
    *   **任务**：综合两路结果，对每种假设给出概率。
    *   **示例**：路1有明确战略解释 + 路2无冲突 → `70%策略调整，10%造假，20%其他`
    *   **输出**：`[异常指标：存货周转率] => [归因：经营滞销(60%)，战略备货(30%)，其他(10%)]`

### 🔹 E层：最终输出打分与报告
*   **E1层：综合置信度打分**
    *   **基础分**：100 分。
    *   **扣分机制（双层扣分）**：
        1.  **C层扣分（偏离度扣分）**：系统内建权重库，影响程度分级：极其严重 -3、有些严重 -1、正向利好 +1。引入偏离度放大：
            *   **实际影响权重 = 基础影响权重 × (1 + MAD偏离度 / 3)**
            *   偏离越大，影响权重越高。
            *   对每条 C 层异常：**期望影响 = Σ(归因概率 × 实际影响权重)**
            *   **C层扣分 = Σ(期望影响 × MAD偏离度)**
        2.  **B+层扣分**：行业性质权重 0，造假权重 -3。乘上严重度修正系数：
            *   存贷双高严重度 = (货币资金/总资产 × 有息负债/总资产)，>0.3 为 5 分。
            *   净现比严重度 = 实际偏离阈值的程度量化，经营现金净额为负时直接锁死最高分。
            *   母子资金分离度 = 差额/总资产，>30% 为最高分。
            *   **B+层扣分 = Σ(权重 × 修正系数)**
    *   **最终得分** = `100 - (C层扣分 + B+层扣分)`，最低 0 分。
*   **E2层：生成结构化报告**
    *   输出四个模块：
        1.  **【整体研判】**：E1 综合得分 + 相似企业横向对比（Top 5 同行的各财务指标一览）。
        2.  **【核心异常与概率归因】**：B+ 和 C 层的异常指标、D 层的概率分布、判断依据（含年报页码或附注名称）。
        3.  **【多空逻辑栈】**：看多支持点与看空风险点。
        4.  **【横向对比表】**：目标公司与 Top 5 最相似同行的 6 维财务特征等级对比。

## 三、系统规则与约束

### 数据流向规则
```
第0层 (PDF → JSON)
   │
   ├─→ A0 (联网搜宏观情报，为 D1 路 2 提供外部知识)
   ├─→ A1 (硬标签查 CSV + LLM 画 6 维数字画像)
   │         │
   │         ▼
   │       A2 (二级行业池 → 余弦相似度 → Top 5 + Top 20%)
   │
   ├─→ B0 (LLM 认表头) → B1 (代码取数 + 勾稽校验)
   │         │
   │         ├─ 校验失败 → 直出 E 层阻断报告
   │         └─ 校验成功 → B+ (逻辑初筛) + C (MAD 偏差)
   │
   └─→ D1 (双路径：路1 查年报原文 + 路2 推演假设)
         │
         └─→ D2 (概率分配) → E1 (打分) → E2 (报告)
```

### 数据契约（PipelineContext）
所有层通过 PipelineContext 共享数据，各层只写自己负责的字段：

| 字段 | 写入层 | 读取层 |
|------|--------|--------|
| raw_doc | 第 0 层 | A/B/D |
| macro_facts | A0 | D |
| tags + financial_profile | A1 | A2 / D |
| benchmark | A2 | C / E |
| financials | B | B+ / C |
| logic_anomalies | B+ | D |
| deviations | C | D |
| reasoning_results | D | E |
| score / report | E | 输出 |

### Prompt 模板清单（8 个文件）
| 文件名 | 用途 |
|--------|------|
| `a0_search_query` | LLM 生成 4 维度联网搜索词 |
| `a0_macro_facts` | 从搜索结果提取宏观事实 |
| `a1_tagging` | 输出 6 维财务等级画像 + 硬标签 |
| `b0_semantic_guide` | 识别报表表头、字段映射 |
| `d1_lookup_notes` | 从年报附注和管理层讨论找异常解释 |
| `d1_hypothesis` | 基于宏观事实和财务画像推演假设 |
| `d2_probability` | 综合双路径结果分配概率 |
| `e2_report` | 生成报告中的多空逻辑栈文本 |

### LLM 调用规范
- 统一网关 `llm/client.py`，支持 Anthropic（主）+ OpenAI（备）
- prompt 模板为 YAML + Jinja2，位于 `config/prompts/`
- 调用方式：`client.chat("prompt_name", {变量字典})`
- 指数退避自动重试，鉴权失败不重试
- API Key 通过 `.env` 文件配置

### 财务数字画像匹配规范（A2 核心）
- 行业池：同花顺二级行业（非三级）
- 数据年限：5 年（不足 5 年取满）
- 多年度合并：逐维中位数
- 等级→数值：极高=1.0，高/中高=0.8，中等=0.5，低=0.2
- 距离算法：余弦相似度
- 输出双池：Top 5（展示）+ Top 20% 保底 5（MAD 基准）

### 行业分类 CSV 数据源
- 文件：`data/industry/thf_industry_classification.csv`
- 来源：同花顺 iFinD，5536 只 A 股
- 列：股票代码、股票简称、同花顺一级/二级/三级行业
- 257 个三级行业 → 映射到更宽的二级行业用于 A2 同行池
- 硬标签获取优先级：CSV 股票代码精确 → 公司名模糊 → LLM 推断 → 关键词规则
