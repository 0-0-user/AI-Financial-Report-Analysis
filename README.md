# AI-Financial-Report-Analysis

AI 驱动的上市公司财报智能分析系统。

## 项目概述

利用大模型能力对上市公司年报进行解读，从财务报表、行业性质等角度分析企业年度经营情况、发展前景与投资价值。

**核心原则**：大模型不碰数学，代码不做语义 — 各司其职，隔离风险。

## 架构速览

```
第0层  PDF提取      →  结构化 JSON
A层    行业定性      →  标签 + 对比基准
B层    财务数据提取  →  统一字段 + 勾稽校验
B+层   内部逻辑检查  →  造假初筛
C层    偏差计算      →  MAD 异常检测
D层    原因推理      →  双路径 + 概率分配
E层    输出报告      →  置信度打分 + 结构化报告
```

## 快速开始

```bash
# 安装依赖
pip install -e .

# 分析一份年报
python scripts/run_pipeline.py --pdf data/raw/600519_2024.pdf
```
